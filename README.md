# Gmail Inbox High-Contrast Restoration via Stylus

This repo is a fork of [nuchi](https://github.com/nuchi)'s original [gmail-inbox-high-contrast-restoration](https://github.com/nuchi/gmail-inbox-high-contrast-restoration) repo, which contains rules for uBlock Origin. Since that's no longer possible to use with the latest version of Chrome, this fork attempts to provide a way to restore the original styles using the [Stylus extension](https://github.com/openstyles/stylus).

Tested with Google Chrome on macos.

## Installation

If you have the Stylus extension installed, you can install the custom gmail style by clicking here: https://github.com/wolfpeyton/gmail-inbox-high-contrast-restoration-stylus/raw/refs/heads/master/gmail-high-contrast-restoration.user.css
